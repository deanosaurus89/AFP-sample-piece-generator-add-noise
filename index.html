AFP Measurement Generator

PW-Measurements 1.2 · nominal + offset + noise + trend · SPC preview · measured values only, no geometry

PolyWorks template: piece UID, properties, and controls. Nominal comes from Measured Value (offset 0, std. dev. 0.1, trend 0, Gaussian). UTF-8 and UTF-16. Replaces the current properties and controls. Add more rows afterwards.

Run

Parts span the first N days of the ISO week (Monday 00:00 UTC, even spacing, small jitter). Trailing digits in Piece base are the first number and the pad width: Piece_000001 for 100 parts is Piece_000001 … Piece_000100. No trailing digits: piece_1 … piece_100. The CSV file and the Piece name field use that same name. Generate opens a save dialog in Chrome/Edge, otherwise a download.

Properties

Comma-separated values: one is picked at random for each part. Empty stays empty. A comma splits the pool; it is not a decimal mark.

Controls

Noise for all / selection

Measured = nominal + offset + noise(mode, std. dev.) + trend from start to end. Offset is a constant shift. Std. dev. is the amplitude (for Gaussian, the standard deviation). Trend is a linear drift across the parts.

Modes: Gaussian (normal), Sine (one period across all parts), Zigzag (alternating +/− std. dev.), Outliers (mostly Gaussian, about 5% of parts at 4–6× std. dev.).

Randomize

Fills offset, std. dev., trend start, trend end, and mode at random. Only >0 stays as it is. Numbers stay inside the min/max you set. Defaults: offset ±0.5, std. dev. 0.05–0.5, trend ±0.3.
